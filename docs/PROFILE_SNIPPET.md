## Tactical Style Fingerprint

An interpretable football tactical-similarity engine built from StatsBomb event data for all 380 matches of the 2015/16 Premier League. It converts five transparent metrics into standardized team fingerprints, calculates Euclidean similarity, and uses a grounded LLM only to explain the result.

- **Try it:** https://tactical-style-fingerprint.vercel.app
- **Repository:** https://github.com/OmTheLast/tactical-style-fingerprint
- **One result:** Liverpool and Tottenham Hotspur are the closest pair in the five-feature model at tactical distance `0.620`.
